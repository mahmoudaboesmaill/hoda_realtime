# مؤسسة سيد عبيد المتكاملة — ElHoda & RT Tech

البوابة الإلكترونية الرسمية لـ **مؤسسة سيد عبيد المتكاملة (ElHoda & RT Tech)** لحلول الكهرباء والإضاءة والأنظمة الذكية والمراقبة.

## الصفحات
- **`index.html`**: الصفحة الرئيسية (البوابة الإلكترونية)
- **`contact.html`**: صفحة قنوات التواصل والموقع وحفظ جهة الاتصال
- **`payment.html`**: صفحة وسائل الدفع والتحويل الإلكتروني السريع (InstaPay & Vodafone Cash)
